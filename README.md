## 📌 Project Overview
SpaceX advertises Falcon 9 rocket launches at approximately **$62 million**, whereas traditional competitors cost upwards of **$165 million**. Much of these substantial cost savings stem from SpaceX’s ability to recover and reuse the Falcon 9 first-stage booster. 

This project is the culmination of the **IBM Data Science Professional Certificate Capstone**. The core objective is to collect, clean, explore, visualize, and apply supervised machine learning models on historical Falcon 9 launch data to predict whether the first-stage booster will land successfully (`Class = 1`) or not (`Class = 0`). This predictive insight enables competing launch providers to estimate launch costs and bid competitively against SpaceX.
